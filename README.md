# Amazon Sales Analysis and Forecasting

## Project Overview
This project analyzes Amazon sales data to identify sales trends, category performance, low-performing products, and revenue patterns. It also uses Linear Regression to forecast future monthly sales.

## Objectives
- Analyze monthly sales trends
- Calculate and analyze net profit
- Identify top-performing product categories
- Identify low-performing products for dead stock analysis
- Perform Pareto (80/20) analysis
- Analyze monthly category-wise sales
- Forecast future sales using Linear Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow
1. Data Loading and Exploration
2. Data Cleaning and Date Conversion
3. Feature Engineering
4. Net Profit Calculation
5. Monthly Sales Trend Analysis
6. Category-wise Revenue Analysis
7. Dead Stock Identification
8. Pareto Analysis
9. Monthly Category Sales Analysis
10. Sales Forecasting using Linear Regression

## Machine Learning Model
The project uses a Linear Regression model to predict future monthly sales based on historical sales data.

## Results
The analysis provides insights into seasonal sales patterns, product category performance, low-performing products, and predicted future sales.
